# 영수강호 세이브 편집기 v0.9

Beast Saga / 灵兽江湖의 `.es3` 세이브를 로컬에서 편집하는 Windows 도구입니다.
기존 v0.8에 **돈 · 동전 수정 버튼**을 추가했습니다. 게임 실행 중 메모리를 바꾸는 트레이너가 아닙니다.

## 설치와 실행

1. Windows 배포 ZIP의 압축을 새 폴더에 풉니다.
2. 게임을 종료하고 세이브 폴더를 별도로 복사해 보관합니다.
3. `BeastSagaEquipmentEditor-v0.9.exe`를 실행합니다.
4. **세이브 .es3 열기**로 실제 플레이 슬롯을 선택합니다. Steam의 게임 관리 → 로컬 파일 보기로 설치 폴더를 열면 `SaveData`에서 슬롯을 찾을 수 있습니다. 설치 위치는 PC마다 다릅니다.
5. 수정 후 변경 목록을 확인하고 **세이브 저장 · 자동 백업**을 누릅니다.
6. 저장 완료 및 백업 경로를 확인하고 파일을 다시 열어 값을 확인합니다. 이후 게임에서 해당 슬롯을 불러옵니다.

`SaveInfo*.es3`는 슬롯 목록용 파일이므로 플레이 세이브로 선택하지 마세요.
관리자 권한 실행은 필수가 아닙니다. 선택한 슬롯과 그 폴더에 쓰기 권한이 필요합니다.

## 환경과 지원 범위

- Windows x64용 WinForms + Microsoft Edge WebView2 앱입니다. .NET Framework 4.8 계열과 WebView2 Runtime이 필요합니다.
- 실제 빌드·실행 검증: Windows 호스트의 .NET Framework Release `534296`, WebView2 SDK `1.0.4258.31`, Python `3.12.10`, Node.js `24.22.0`.
- 게임 Steam App ID `2232880`, 로컬 설치 build ID `25950135` 환경의 세이브 복사본에서 돈 필드 읽기·수정·저장 후 다시 읽기를 확인했습니다. 이전 v0.8 검증용 세이브 복사본으로 기존 기능도 회귀 검사했습니다.
- 게임 버전 전체, 다른 모드·플랫폼, 실제 게임에서 수정 세이브를 불러오는 과정은 검증하지 않았습니다. build ID가 같아도 모든 세이브의 동작을 보장하지 않습니다.
- 지원 입력은 10 MiB 이하의 기존 영수강호 표식이 있는 UTF-8 텍스트 `.es3`입니다. 암호화·압축 세이브와 손상된 구조는 지원하지 않습니다.
- macOS/Linux용 EXE는 제공하지 않습니다. HTML 보조판은 직접 파일 교체 대신 다운로드 방식이며, 이 릴리스의 주 검증 대상은 Windows EXE입니다.

## 기능별 사용법

### 돈 수정

1. 세이브를 연 뒤 상단 **돈 · 동전 수정 (현재 금액)** 버튼을 누릅니다.
2. 주인공 보유 동전 `铜钱` 항목이 선택됩니다. **보유 금액 선택 (동전)**에서 값을 고르거나 직접 입력합니다.
3. **0~1,000,000 사이의 정수**를 입력하고 변경 목록을 확인한 뒤 저장합니다.

이 범위는 편집기의 보수적인 입력 제한입니다. 게임 자체의 최대 보유 금액으로 확인한 값이 아닙니다.
0은 기존 동전 레코드의 수량을 0으로 바꾸며 레코드를 삭제하지 않습니다.
음수, 소수, 지수 표기, 쉼표, 공백, 빈 값, 앞의 불필요한 0은 거부합니다.
잘못 입력한 상태에서는 저장이 비활성화됩니다. 올바르게 고치거나 해당 입력을 취소하세요.

수정 위치는 `/savePlayerData/value/ItemHad/铜钱/_Count` 하나입니다.
상점의 동전이나 다른 캐릭터·기록의 값을 일괄 변경하지 않습니다.
동전 레코드가 없거나 형식이 다르면 버튼이 비활성화되며 새 레코드를 만들지 않습니다.
일반 아이템 탭에서 동전을 수정해도 같은 변경 목록을 사용하므로 금액이 이중 적용되지 않습니다.

### 주인공 능력치

**주인공 · 능력치** 탭에서 레벨과 기본 능력치를 입력합니다.
레벨 1~1,000, 기본 능력치 1~100,000은 편집기 제한입니다.
능력치·주인공 장착 옵션 변경 시 지원되는 장비·내공·특성을 반영해 기혈을 계산합니다.
음식 효과나 부착 장비 등 미지원 조건에서는 계산 오류가 표시될 수 있으며 저장을 강행하지 마세요.
진기·방어력 등 게임이 계산하는 모든 표시 수치를 직접 편집하는 기능은 아닙니다.

### 특성·생활 포인트

**특성·생활 포인트** 탭에서 다음 값을 설정합니다.

| 항목 | 의미 |
| --- | --- |
| 특성 포인트 · 누적 추가분 | 현재 남은 포인트가 아니라 `TalentAdd` 추가분 |
| 능력치 포인트 · 누적 추가분 | `AddProSpot` 추가분, 사용한 기록 유지 |
| 생활 포인트 · 남은 수량 | 남은 포인트 직접 설정 |
| 의술 레벨 | 1~100, 변경하면 해당 레벨의 시작 경험치로 설정 |

포인트 입력은 0~1,000,000입니다. 모든 생활 기술이 1레벨이면 생활 포인트가 0으로 고정됩니다.
양수 포인트가 필요하면 의술 레벨을 11 이상으로 명시적으로 변경해야 합니다.
의술 레벨을 바꾸지 않으면 기존 레벨 내 경험치 진행분을 보존합니다. 배운 특성 목록은 편집하지 않습니다.

### 동료

**동료 · 능력치**에서 합류·이탈 동료를 선택하고 표시된 기본 능력치와 포인트를 입력합니다.
여러 동료의 변경을 함께 저장할 수 있습니다. 체백·장착 옵션 변경 시 지원되는 조건에서 기혈을 연계 계산합니다.
동료 생성·영입·삭제 기능은 제공하지 않습니다.

### 아이템과 장비

- **일반 아이템 · 수량**: 기존 보유 항목의 수량 1~1,000,000을 수정합니다. 동전만 0을 허용합니다. 새 아이템 생성·일반 아이템 삭제는 지원하지 않습니다.
- **장비 · 옵션**: 보유·장착 장비의 기존 옵션 슬롯에서 종류·등급을 선택합니다. 슬롯 수를 유지하며 중복 옵션은 차단합니다. 장비 복제·수량 편집은 지원하지 않습니다.
- 전체 기술 선택은 실험적입니다. 장비용으로 설계되지 않은 기술이 포함되며 조합의 게임 내 효과는 검증하지 않았습니다.
- 이름 검색, 카테고리·세부 분류, 정렬, 페이지 크기·페이지 이동을 사용할 수 있습니다. 수량 정렬은 저장된 값을 기준으로 합니다.
- 입력은 변경 목록에 자동 반영됩니다. 탭·페이지를 바꾸어도 대기 입력은 유지됩니다. **변경 모두 취소**는 아직 저장하지 않은 변경만 취소합니다.

## 백업과 복원

EXE는 저장 전에 같은 폴더에 `슬롯.es3.backup-날짜-고유번호.bak`를 새로 만들고 원본 바이트와 일치하는지 확인합니다.
그 후 선택한 슬롯에 쓰고 다시 읽어 검증합니다. 기존 백업은 덮어쓰지 않습니다.
저장 중 오류가 나면 원래 내용을 복구하려고 시도합니다. 복구까지 실패했다는 메시지가 나오면 게임을 실행하지 말고 백업을 복원하세요.

수동 복원:

1. 게임과 편집기를 종료합니다.
2. 현재 슬롯을 다른 폴더에 복사합니다.
3. 원하는 시점의 `.bak` 파일을 복사해서 원래 슬롯 이름(예: `custom1.es3`)으로 되돌립니다.
4. 게임에서 슬롯을 불러와 확인합니다.

이 앱은 Steam Cloud를 제어하지 않습니다. 동기화로 파일이 되돌아가는 경우 해당 서비스의 상태와 백업 시점을 확인하세요.
브라우저 HTML의 **원본 백업 다운로드**는 별도 파일 다운로드입니다. EXE 자동 백업을 대체하는 설명이 아닙니다.

## 제약과 문제 해결

| 상황 | 확인할 내용 |
| --- | --- |
| 화면이 뜨지 않음 | WebView2 Runtime 설치 상태와 .NET Framework 환경 확인 |
| 돈 버튼이 비활성 | 먼저 정상 세이브를 열었는지, 기존 주인공 동전 레코드가 있는지 확인 |
| 저장 버튼 비활성 | 변경이 없거나 잘못된 입력이 남아 있음. 변경 검토 영역 확인 |
| 외부 변경 오류 | 게임·클라우드 등에서 파일이 바뀜. 세이브를 다시 열고 편집 |
| 파일 잠금·권한 오류 | 게임과 다른 편집기를 종료하고 파일/폴더 쓰기 권한 확인 |
| 기혈 계산 오류 | 미지원 음식/부착물/카탈로그 차이 가능. 원본 보존, 관련 변경 취소 |
| 알 수 없는 아이템 | 저장 이름 그대로 표시될 수 있음. 내장 카탈로그는 자동 업데이트되지 않음 |
| 저장 실패 및 복구 실패 | 게임 실행 중지, 표시된 백업 경로에서 수동 복원 |

네트워크 공유·심볼릭 링크 등 리파스 포인트 경로는 지원하지 않습니다.
앱은 게임 프로세스가 감지되면 실제 슬롯 저장을 거부하지만 모든 동기화 프로그램을 감시하지는 않습니다.
정전·디스크 고장까지 무손실을 보장하는 기능은 아닙니다. 별도 폴더의 백업을 유지하세요.

## 소스 빌드

필수: Windows x64, .NET Framework C# 컴파일러, Python 3.12 이상. 테스트에는 Node.js가 필요합니다.
WebView2 SDK는 Microsoft의 `Microsoft.Web.WebView2` NuGet 패키지에서 준비합니다. 검증 버전은 `1.0.4258.31`입니다.
SDK의 .NET Framework용 `Microsoft.Web.WebView2.Core.dll`, `Microsoft.Web.WebView2.WinForms.dll`,
x64 `WebView2Loader.dll`, 해당 `LICENSE.txt`를 하나의 로컬 폴더에 준비하세요.
다른 버전 DLL을 섞지 마세요. 빌드 스크립트는 다운로드·패키지 설치·게임 파일 읽기를 하지 않습니다.

```powershell
python build.py --webview2 .\vendor\webview2
node tests\money.cjs
```

결과는 `dist/BeastSagaEquipmentEditor-v0.9.exe`와 `.html`입니다.
추가 저장 모듈 테스트는 새 임시 폴더에서 실행할 수 있습니다.

```powershell
& "$env:WINDIR\Microsoft.NET\Framework64\v4.0.30319\csc.exe" /nologo /out:SaveStoreTests.exe src\SaveStore.cs tests\SaveStoreTests.cs
.\SaveStoreTests.exe .\test-new-folder
```

개인 세이브를 검사하려면 원본을 별도 테스트 폴더에 복사한 후
`node tests\money.cjs <복사한-세이브.es3> <별도-출력.es3>`를 사용합니다.
입력·출력에 같은 경로를 지정하지 마세요. 개인 세이브를 저장소나 배포 파일에 넣지 마세요.

`--self-test` EXE 옵션은 기존 개발 회귀 시나리오용입니다. 특정 동료·아이템이 있는 비공개 테스트 복사본을 전제로 하므로 일반 사용자의 세이브에서는 실패할 수 있습니다.

## 검증 기록과 배포 구성

돈 숫자 검증·0/상한·무변경 바이트 보존·비대상 바이트 보존·아이템 동시 변경을 테스트했습니다.
실제 EXE에서 금액 1,000,000 및 0 저장 후 다시 열기, 잘못된 입력 저장 차단, 탭 이동 시 입력 보존을 확인했습니다.
기존 주인공·합류/이탈 동료·포인트·장비 옵션·카테고리 필터·200개 이후 항목 수정,
연속 저장의 백업 일치 검사도 통과했습니다. 저장 모듈은 잠금·외부 변경·실패 복구 등 16개 검사를 통과했습니다.
검사에 실제 원본 슬롯을 덮어쓰지 않았습니다. 게임 내 불러오기 검사는 **NOT_RUN**입니다.

배포는 실행 파일·HTML 보조판·README·검증 요약·SHA-256 목록·WebView2 고지로 구성합니다.
개인 세이브, 브라우저 프로필, 로컬 경로, 자격 증명, 게임 실행 파일·원본 asset 파일은 포함하지 않습니다.
기존 에디터의 정적 이름·옵션·능력치·분류 카탈로그는 유지됩니다. 게임 업데이트에 따라 다를 수 있습니다.
이 프로젝트에 새 오픈소스 라이선스를 임의 부여하지 않았습니다. 포함된 제3자 고지는 해당 구성 요소에만 적용됩니다.
