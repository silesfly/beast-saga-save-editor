주인공 능력치와 기혈 자동 연계

입력 범위: 레벨 1~1,000, 능력치 1~100,000 (편집기 제한). 기본 능력치를 입력하세요. 장비·특성 보정은 계산 시 추가됩니다.

기본·최대·현재 기혈과 6개 기본 능력치 기록을 함께 저장합니다. 진기·방어력·공격 효과 등 별도 저장 필드가 없는 수치는 게임이 불러올 때 계산합니다. 음식 효과가 남아 있거나 부착물이 있는 장비는 자동 계산을 지원하지 않습니다.

주인공 특성·생활 포인트

특성·능력치 포인트는 원본 편집기와 같은 누적 추가분입니다. 이미 사용한 포인트와 배운 특성은 유지됩니다. 현재보다 10을 높이면 추가 포인트도 10 늘어납니다. 생활 포인트는 남은 수량을 직접 설정합니다.

모든 생활 기술이 1레벨이면 생활 포인트가 0으로 고정됩니다. 이 경우 의술 레벨을 11 이상으로 설정하세요. 의술 레벨을 바꾸면 해당 레벨 시작 경험치로 저장합니다. 입력 즉시 변경 목록에 반영됩니다.

동료 편집

입력 즉시 변경 목록에 반영됩니다. 여러 동료를 수정한 뒤 세이브 저장으로 한 번에 적용하세요. 체백을 바꾸면 동료의 장비·내공·레벨 특성을 반영해 기혈도 자동 계산합니다. 입력 범위 0~1,000,000은 편집기 제한입니다.

    수정본은 *.ITEMS-EDITED.es3로 저장됩니다. 게임 폴더의 원본을 다운로드 대상으로 지정하지 마세요. 게임 실행·클라우드 동기화 감시는 하지 않습니다.

    게임 데이터의 장비 옵션 49종과 전체 기술 370종을 선택할 수 있습니다. 전체 기술은 장비용으로 설계되지 않은 효과를 포함합니다. 옵션 개수는 유지하고 중복은 차단합니다. 새 조합의 게임 내 효과나 허용 수량 상한까지 검증된 것은 아닙니다. 원본 백업을 보관하세요.
